MALEEKA BIRTHDAY SURPRISE — BLACK & GOLD EDITION

FILES
- index.html: the website structure and message
- style.css: black, gold, rose-red cinematic design
- script.js: intro, falling sparkles, photo lightbox, final wish
- photos/: six photographs used in the memory gallery

PREVIEW ON YOUR COMPUTER
1. Open this folder in Visual Studio Code.
2. Double-click index.html, then open it in your browser.
3. For best results, install the Live Server extension in VS Code, right-click index.html, and choose Open with Live Server.

PUBLISH ON GITHUB PAGES
1. Create a new public repository on GitHub.
2. Upload index.html, style.css, script.js, README.txt, and the photos folder (keep the photos inside the folder).
3. Open Settings > Pages.
4. Under Build and deployment, choose Deploy from a branch.
5. Choose main and /(root), then Save.
6. Wait for the deployment to finish. Your site URL will look like:
   https://YOUR-USERNAME.github.io/REPOSITORY-NAME/

Keep the filenames and folder structure exactly as they are.
